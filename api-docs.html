API documentation

Last updated: August 9, 2026

ConvertFlow and Web Gadgets tools are primarily browser-based utilities. A public developer API is not generally available at this time.

Current status

There is no stable, documented public HTTP API for third-party integrations yet. Features you see on the site (upload, convert, download) are intended for interactive use on web-gadgets.com.

If you need programmatic access

If you are building a product and need conversion via API, contact us with your use case. We may share private options, rate limits, or a roadmap when available.
